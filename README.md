# The Gentleman — Appointment Manager

A simple appointment scheduling web app developed for a local hair salon.

**Live demo:** https://ingrojoia.github.io/-the-gentleman/

## About the project

The Gentleman started as a personal project to help my mother manage her appointments at her hair salon.

Most of her clients contact her through WhatsApp or phone calls, so she needed a quick way to check her availability without going through multiple messages.

Instead of building a complicated booking system, I decided to focus on something simple: an app where she could check her schedule, add appointments, and make changes whenever necessary.

The application was designed primarily for iPhone, with a blue-and-white interface based on the salon's colors.

## Features

- Daily, weekly, and monthly calendar views.
- Add, edit, and delete appointments.
- Custom appointment durations depending on the service.
- Check available time slots.
- Detect overlapping appointments.
- 12-hour time format (AM/PM).
- Local data storage.
- Backup export and import.
- Offline support through PWA technology.

## Technologies

- HTML
- CSS
- JavaScript
- Browser local storage
- Service Worker
- Web App Manifest
- GitHub Pages

The application runs directly in the browser and stores appointment information on the user's device. It doesn't require a database server.

## Development

I started by identifying the main problems my mother had when organizing appointments.

One of the biggest challenges was handling different service durations. A regular haircut might take 30 minutes, while a cleanup could take 20 minutes, and other services might require more time.

During testing on an iPhone, I also encountered issues with modal windows that caused the interface to become unresponsive after saving an appointment. I worked on correcting these issues through several updates.

Another improvement came from user feedback: my mother preferred the 12-hour clock instead of the 24-hour format, so I updated the interface.

The project is currently being tested in everyday use, and I plan to keep improving it based on her experience.

## Future improvements

- Improve appointment management and navigation.
- Add support for multiple hairstylists.
- Improve the backup system.
- Continue testing performance and usability.

# The Gentleman — Gestor de citas

Aplicación web desarrollada para organizar las citas de una peluquería.

**Aplicación:** https://ingrojoia.github.io/-the-gentleman/

## Sobre el proyecto

The Gentleman nació como un proyecto personal para ayudar a mi mamá a organizar las citas de su peluquería.

La mayoría de sus clientes se comunican con ella por WhatsApp o mediante llamadas telefónicas. Esto hacía que tuviera que revisar conversaciones para recordar los horarios que ya tenía ocupados.

Mi idea fue desarrollar una aplicación sencilla donde pudiera consultar su agenda, registrar clientes y modificar citas sin complicarse demasiado.

Desde el principio decidí enfocarme únicamente en sus necesidades, sin agregar sistemas de reservaciones para clientes ni funciones que realmente no utilizaría.

También busqué que la interfaz fuera cómoda para utilizarla desde su iPhone, manteniendo los colores azul y blanco de su negocio.

## Funcionalidades

- Calendario diario, semanal y mensual.
- Registro, edición y eliminación de citas.
- Duración personalizada según el servicio.
- Consulta de horarios disponibles.
- Detección de citas que se superponen.
- Horarios en formato de 12 horas (a. m./p. m.).
- Almacenamiento local de información.
- Exportación e importación de respaldos.
- Funcionamiento sin conexión mediante PWA.

## Tecnologías utilizadas

- HTML
- CSS
- JavaScript
- Almacenamiento local del navegador
- Service Worker
- Web App Manifest
- GitHub Pages

La aplicación funciona directamente desde el navegador y almacena las citas en el dispositivo. No necesita un servidor de base de datos.

## Desarrollo

Primero analicé cómo organiza normalmente sus citas mi mamá y cuáles eran las funciones que realmente necesitaba.

Uno de los puntos importantes fue permitir diferentes duraciones para cada servicio. Por ejemplo, un corte normal puede durar 30 minutos, mientras que una limpieza tarda aproximadamente 20 minutos. También existen servicios que requieren más tiempo, por lo que no era conveniente manejar horarios completamente fijos.

Durante las pruebas en iPhone encontré algunos problemas con las ventanas emergentes. Después de guardar una cita, la interfaz podía quedarse bloqueada, así que fui realizando correcciones y actualizaciones.

También hice cambios a partir de los comentarios de mi mamá. Uno de ellos fue modificar el formato de las horas, ya que prefería visualizar los horarios de 1 a 12 con a. m. y p. m.

Actualmente la aplicación se encuentra en una etapa de pruebas con una usuaria real. Mi intención es continuar mejorándola conforme surjan nuevas necesidades.

## Próximas mejoras

- Optimizar la navegación y el registro de citas.
- Permitir administrar las agendas de otras peluqueras.
- Mejorar las opciones de respaldo.
- Continuar realizando pruebas de funcionamiento.
